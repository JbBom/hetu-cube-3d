# v1.0.2

This release upgrades the public GitHub Pages entry from the original Hetu Cube showcase to the new Hetu Luoshu interactive learning experience.

## Changes

- Replaced the root `index.html` with the new packaged static app.
- Added bundled `assets/` JavaScript and CSS files for the new learning interface.
- Added Hetu/Luoshu learning modes, comparison mode, concept cards, intro flow, quiz content, and share entry.
- Synced the same web assets into the optional iOS `WKWebView` shell under `HetuCubeIOS/HetuCubeIOS/Web/`.
- Updated `README.md` to describe the new "河图洛书交互学习器" positioning.

## Notes

- `hetu-cube.html` is retained as the historical standalone Hetu Cube page.
- GitHub Pages continues to use the repository root and `.nojekyll`.
