# v1.0.8

This release improves the Hetu Cube 3D teaching experience.

## Highlights

- Reworked the 3D presentation from a decorative effect into a clearer learning model.
- Added more readable teaching labels for:
  - Heaven plane and earth plane
  - Hetu generating pairs
  - Center axis labels for 5 and 10
  - Vertex number and trigram markers
- Added directional relation cues:
  - Subtle glowing tracks for each generating pair
  - Arrow markers showing the generating direction
  - Focus-stage labels such as `水 1→6 · 差 5 · 生成对`
- Reduced visual noise:
  - Lower star density and opacity
  - Thinner yin-yang rotating paths
  - Cleaner full-model state with fewer always-on cards
- Improved Three.js sprite rendering so teaching labels remain readable from different camera angles.
- Updated the README feature table to describe the new teaching-demo behavior.
- Bumped the PWA cache name to `hetu-cube-v1.0.8`.

## Notes

The goal of this release is comprehension first: the model should help learners see number, position, pairing, direction, and phase progression more clearly.
