# Release v1.0.0

## Summary

First public release of `hetu-cube-3d`.

This version packages the interactive Hetu Cube visualization as a GitHub-ready static project with a local Three.js dependency, publishable entry files, and an optional iOS wrapper.

## Included

- interactive 3D visualization page
- GitHub Pages friendly `index.html`
- local `three.min.js`
- iOS WebView wrapper project
- project README
- MIT License
- third-party notice for Three.js

## Release notes

- cleaned up debug output in the main HTML page
- clarified bundled dependency comments
- added publish-ready documentation and license files
- prepared repository structure for static hosting
