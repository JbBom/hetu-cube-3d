# Release v1.0.1

## Summary

This release packages the post-launch polish for `hetu-cube-3d`, mainly focused on GitHub presentation, GitHub Pages readiness, and consistency between the web entry point and the optional iOS shell.

## Included

- polished GitHub homepage README
- repository banner asset for project presentation
- GitHub Pages ready root entry with `.nojekyll`
- aligned `index.html` loading for the iOS WebView shell
- static hosting friendly repository structure

## Release notes

- upgraded the repository homepage into a more formal open-source showcase page
- added a reusable SVG banner for GitHub display
- kept `index.html` as the canonical Pages entry point
- ensured the iOS shell prefers `index.html` and falls back to `hetu-cube.html`
- completed the public Pages deployment path for the repository
